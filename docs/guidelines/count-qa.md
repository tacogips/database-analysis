# 全件数取得のQ&A一覧

製品別ガイドの同じファイルに、件数取得フロー・実行手順・Q&Aをまとめています。

- [MySQL InnoDBのQ&A](mysql-innodb.md#qa)：RDS read replica、重いSELECTとサービス性能、slow query log、精度の観測、COUNTのSQL。
- [MySQL MyISAMのQ&A](mysql-myisam.md#qa)：保持件数・統計キャッシュ・ロックとコピー先の制約。
- [SQL ServerのQ&A](sql-server.md#qa)：read replica／AG、重いSELECTとサービス性能、診断収集、精度の観測、COUNT_BIGのSQL。

共通する質問は両方に置き、複製・ロック・統計・ログの仕様に応じて回答しています。実行手順は[MySQL](mysql-innodb.md#実行手順)／[SQL Server](sql-server.md#実行手順)を参照します。
